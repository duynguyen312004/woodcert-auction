# Frontend Dispute Module

Implemented through the order and admin features:

- the buyer opens a case and may cancel it while active;
- buyer and seller have dedicated dispute-file routes with the complete timeline;
- buyer, seller, and authorized admin can post immutable text/image messages;
- active files poll every 10 seconds and closed files switch to read-only mode;
- opening evidence remains separate from message attachments in compact history responses;
- all dispute statuses, author roles, and outcomes use shared Vietnamese labels;
- admin queue, full detail, clarification messages, review, and final resolution.
